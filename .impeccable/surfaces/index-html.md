# NEXUS resource workspace surface

Scope: a code-led buildless web prototype with four hash views: overview, Action studio, Community and Impact ledger. Visitor mode is Operate. The desktop audience is a township manager comparing one Water + BioLoop intervention; Community demonstrates a resident wallet and staff hand-off.

The job is to inspect a resource connection, test allocation and cost assumptions, approve a feasible plan, and follow its operational/accounting trail. Overview presents balances above a schematic map and linked inspector. Action studio places live estimates beside controls and work orders. Community puts the wallet first on a phone. The ledger shows the same intervention with source classes and an evidence download.

The memorable moment is continuity: selecting Tank A, Zone B or the nursery and changing allocation or delivery mode affect the same connected plan. On a phone, map selection opens that resource in a native bottom sheet. Motion explains change; reduced-motion preferences remove it.

The body comment in `index.html` names resource mission control: forest rail, botanical canvas, schematic map and interlocking N. `nexus-resource-studio-02` is an implementation identifier. No approved external seed, selected image comp or user comparison workshop is evidenced by supplied source. This brief records the result rather than reconstructing approval history.

Proof is explicit: retained public climate data, original official forecast dates, tariff references, calculation receipts and an append-style local trail. Published/public, derived model, site assumptions and simulated outcome remain distinct. Negative economics and physical constraints remain visible; human approval cannot bypass hard limits.

Limitations: illustrative site/map; assumed stock, costs and identities; simulated operations, credits and outcomes; editable browser storage. Official weather refresh uses the local adapter with a saved-data fallback. There is no production authentication, real dispatch, payment, sensor feed, immutable audit service or configured cloud publishing. English copy is an implementation assumption.

The final source places “Good things start locally.” below “Hello, Nurul.” and omits decorative page prefixes and the former opportunity eyebrow. These are local copy/layout decisions, not global brand rules.

Unresolved production work includes real site inputs, quality evidence, measured outcomes and operational integrations. They are not claimed by the prototype. `DESIGN.md` owns shared visual rules; this brief owns surface strategy.

V0.3 extends this world with a default Live outlook: current public model weather, numeric forecast rain/ET₀, one-minute polling and captured plan inputs. The live panel is the first operational content; historical scenarios retain their meaning. Action-specific, dismissible resource-flow, tank, bed and wallet animations show what changed immediately. Device stock stays explicitly unconnected/simulated.

The v4 refinement removes the auxiliary Identity page, increases ordinary prose to 16px, and adds engine-backed plan presets, disclosure-preserving summary copy, per-day playback, map camera focus and evidence filters. Mobile preserves the reading scale with a two-column scenario selector and a compact non-overflowing header.
